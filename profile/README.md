## 🍂 어떤 서비스인가요

단풍 예측은 넓은 지역 단위로만 나오고, "지금 우리 구가 어떤지"는 직접 가 봐야 압니다.
까우룽까우룽은 그 자리에 있는 사람이 **직접 찍은 사진**으로 단풍 상황을 알려 주고, 모두가 함께 보는 지도로 만듭니다.

- 사용자가 서울 25개 구에서 단풍 사진을 **직접 촬영해 제보**하면
- **AI(CLOVA Studio HCX-005)가 단풍 사진인지 검증**하고, 애매하면 운영자가 검토해 공개하고
- 지도에는 **구별 단풍 단계와 관심도 나무가 1분마다** 갱신됩니다
- 제보가 부족한 구는 **산림청 2026 단풍 절정 예측**을 기본값으로 보여 줍니다

하단 탭은 **지도 · 피드 · 제보 · 나무** 4개로 구성됩니다.

## ✨ 주요 기능

### 📸 직접 촬영 제보
- 갤러리 업로드 없이 **웹 카메라로만** 촬영해 현장 사진만 받습니다.
- 위치 권한을 허용하면 현재 위치로 구가 자동 설정되고, 좌표가 **해당 구 경계 안일 때만** 제출됩니다.
- 단계(물들기 전 · 물드는 중 · 절정 · 낙엽)와 수종(단풍 · 은행 · 혼합)을 함께 고릅니다.
- 사진의 EXIF·GPS 정보는 지워서 비공개로 저장합니다.

### 🤖 AI 검증과 운영자 검토
- 제보는 접수 즉시 응답하고, 검증은 서버 워커가 비동기로 처리합니다.
- AI 판정 결과는 **승인 / 검토 / 반려**이고, 검토 건은 운영자가 확인합니다. 승인된 제보만 피드와 지도에 공개됩니다.
- 비용 통제를 위해 AI 동시 호출 2개, 응답 토큰 상한, 토큰 사용량 로그를 둡니다.

### 🗺️ 1분마다 바뀌는 단풍 지도
- **제보 우선**: 최근 3일 승인 제보가 3건 이상이면 최신 제보 다수결로 구의 단계를 정합니다.
- **예측 보완**: 제보가 부족하면 산림청 예측 절정일과 오늘 날짜의 차이로 단계를 계산합니다.
- 지도에는 각 구가 **제보 기반**인지 **예측 기반**인지 함께 표시됩니다.

| 오늘 − 예상 절정일 | 단계 |
|---|---|
| 14일 이상 전 | 🟢 물들기 전 |
| 4~13일 전 | 🟡 물드는 중 |
| ±3일 | 🍁 절정 |
| 4일 이상 지남 | 🍂 낙엽 |

### 🌳 관심도 나무
최근 7일 승인 제보를 기준으로 구마다 관심도를 계산해, 지도 위에 **나무 0~3그루**로 보여 줍니다.

> 관심도 = 제보 수 × 2 + 서로 다른 제보자 수 × 3 + 좋아요 수

### 🌱 포인트와 나만의 나무
- 제보가 처음 승인되면 **20P**를 적립합니다 (제보 1건당 1회).
- 나무는 **단풍 · 은행 · 벚꽃 · 크리스마스 트리** 4종이며, 누적 포인트에 따라 새싹 → 묘목 → 어린나무 → 큰나무로 자랍니다.
- 포인트로 나무 종류별 전용 아이템(꼭대기 · 가지 · 바닥 · 배경)을 사서 꾸밀 수 있습니다.

## 🏗️ 시스템 구조

```text
사용자 ──▶ Load Balancer ──▶ API 서버 KR-1 · KR-2 (FastAPI, Auto Scaling)
                                    │
                    Cloud DB for MySQL (Master + 다른 존 Standby)
                                    │  작업 큐
                         검증·집계 워커 ──NAT Gateway──▶ CLOVA Studio (HCX-005)
                                    │
                         Object Storage (제보 사진 비공개 · 지도 JSON)
```

- VPC를 **Public / Private API / Private DB** 3계층으로 나누어 API와 DB는 외부에서 직접 닿지 않습니다.
- 검증·집계 워커가 DB 작업 큐를 읽어 AI 검증과 1분 집계를 수행하고, 결과를 지도 JSON으로 Object Storage에 올립니다.
- 중복 제출(Idempotency-Key), 포인트 이중 적립(적립 키), 워커 중복 처리(작업 잠금 토큰)를 각각 막습니다.
- Cloud Insight로 서버 CPU·메모리를 모니터링합니다.

| 영역 | 사용 기술 |
|---|---|
| Backend | Python, FastAPI, SQLAlchemy, Alembic |
| Data | Cloud DB for MySQL, Object Storage |
| AI | CLOVA Studio (HCX-005) |
| Infra | NAVER Cloud Platform (VPC, Load Balancer, Auto Scaling, NAT Gateway, Cloud Insight) |
| Map | Naver Maps, 서울 25개 구 경계 폴리곤 |
